
# Lección 1: ¿Qué es Java y la programación?

**Duración:** 8 minutos y 12 segundos aproximadamente  
**Herramienta:** OnlineGDB  
**Práctica:** `starter-files/lesson-01`

## Objetivo

Comprender qué es la programación, conocer el lenguaje Java y aprender a escribir y ejecutar un primer programa utilizando un editor en línea.

## Contenido de la lección

### Escena 1: Introducción

**Pantalla:** Presentación del curso Java para principiantes.

**Narración:**

Bienvenido a nuestro curso de Java para principiantes. En esta primera lección aprenderás qué es la programación, para qué sirve Java y cómo ejecutar tu primer programa.

### Escena 2: ¿Qué es programar?

**Pantalla:** Explicación del concepto de programación mediante ejemplos cotidianos.

**Narración:**

Programar consiste en escribir instrucciones para que una computadora realice determinadas tareas. Estas instrucciones deben estar organizadas de manera lógica y seguir un orden.

### Escena 3: ¿Qué es Java?

**Pantalla:** Presentación del lenguaje Java y ejemplos de aplicaciones.

**Narración:**

Java es un lenguaje de programación utilizado para desarrollar diferentes tipos de aplicaciones. Es ampliamente conocido y permite aprender conceptos fundamentales de programación.

### Escena 4: ¿Cómo funciona un programa?

**Pantalla:** Explicación del proceso de escritura, compilación y ejecución.

**Narración:**

Primero escribimos el código fuente. Después, un compilador lo transforma en instrucciones que pueden ejecutarse mediante la máquina virtual de Java. Finalmente, el programa muestra sus resultados.

### Escena 5: Conociendo OnlineGDB

**Pantalla:** Editor de Java en línea.

**Narración:**

Para practicar utilizaremos OnlineGDB, una herramienta que permite escribir y ejecutar código Java directamente desde el navegador, sin instalar programas adicionales.

### Escena 6: Nuestro primer programa

**Pantalla:** Código Java y consola de ejecución.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hola, mundo!");
    }
}
```

**Narración:**

Este es nuestro primer programa en Java. La instrucción `System.out.println` permite mostrar un mensaje en la consola. Al ejecutar el programa, veremos el texto Hola, mundo.

**Pantalla:** Resumen de lo aprendido.

**Narración:**
