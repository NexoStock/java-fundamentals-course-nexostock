
# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de aproximadamente una hora introduce a estudiantes de secundaria al mundo de la programación utilizando Java. A través de siete lecciones progresivas, los participantes aprenderán los fundamentos de la programación, desde la utilización de variables y operadores hasta los conceptos de programación orientada a objetos.

El curso está diseñado para facilitar el aprendizaje mediante explicaciones sencillas, ejemplos prácticos y actividades que permiten aplicar los conocimientos adquiridos en cada lección.

**¡No necesitas descargar ni instalar programas!** Todas las actividades se realizan directamente desde el navegador utilizando OnlineGDB, un entorno de programación en línea que permite escribir, ejecutar y probar programas en Java.

**Duración total:** 52 minutos y 42 segundos.

**Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa en programación.

**Prerrequisitos:** Ninguno. Solo se necesitan conocimientos básicos para utilizar una computadora y un navegador web.

**Herramientas necesarias:** Un navegador web actualizado (Google Chrome, Mozilla Firefox, Safari o Microsoft Edge) y conexión a Internet.

**Repositorio de código fuente:**

[https://github.com/NexoStock/java-fundamentals-course-nexostock](https://github.com/NexoStock/java-fundamentals-course-nexostock)

## Objetivos del Curso

Al finalizar el curso, los estudiantes serán capaces de:

- Comprender qué es la programación y reconocer las características fundamentales del lenguaje Java.
- Declarar y utilizar variables, tipos de datos y operadores.
- Implementar estructuras condicionales y repetitivas para controlar el flujo de un programa.
- Crear métodos para organizar y reutilizar instrucciones.
- Comprender los conceptos de clases, objetos y constructores.
- Aplicar encapsulación mediante atributos privados, getters y setters.
- Utilizar arreglos para almacenar y gestionar información.
- Identificar errores comunes y aplicar buenas prácticas de programación.
- Desarrollar pequeños programas utilizando los conceptos aprendidos durante el curso.

## Secuencia de las Lecciones

El curso está organizado en siete lecciones progresivas. Cada una introduce nuevos conceptos mediante explicaciones y ejemplos prácticos. Asimismo, se incluyen actividades para que los estudiantes puedan experimentar con el código y reforzar lo aprendido.

### Lección 1: ¿Qué es Java y la programación?

**Duración:** 7 minutos y 28 segundos.

**Descripción:** Aprende qué significa programar, conoce el lenguaje Java y ejecuta tu primer programa utilizando un editor en línea.

**Temas principales:** Introducción a la programación, lenguaje Java y salida de información en consola.

**Conclusiones clave:** Programar consiste en proporcionar instrucciones ordenadas a una computadora. La instrucción `System.out.println` permite mostrar mensajes en la consola.

### Lección 2: Variables, tipos de datos y operadores

**Duración:** 10 minutos y 30 segundos.

**Descripción:** Aprende a almacenar información mediante variables y realiza operaciones matemáticas utilizando diferentes tipos de datos.

**Temas principales:** Variables, tipos de datos `int`, `double`, `String`, `boolean` y operadores aritméticos.

**Conclusiones clave:** Las variables permiten almacenar información durante la ejecución de un programa. Java utiliza diferentes tipos de datos para representar números, textos y valores lógicos. Los operadores permiten realizar cálculos y trabajar con esos datos.

**Duración:** 6 minutos y 2 segundos.

**Descripción:** Conoce los fundamentos de la programación orientada a objetos y crea una mascota virtual utilizando clases, objetos y constructores.

**Temas principales:** Clases, objetos, atributos, métodos y constructores.

**Conclusiones clave:** Una clase representa un modelo o estructura a partir de la cual se crean objetos. Los objetos contienen atributos y métodos. La palabra reservada `new` permite crear instancias de una clase y los constructores inicializan sus datos.

### Lección 6: Encapsulación, arreglos y tu primer programa

**Duración:** 7 minutos y 18 segundos.

**Descripción:** Aprende a proteger los datos mediante la encapsulación y utiliza arreglos de objetos para desarrollar un pequeño registro de estudiantes.

**Temas principales:** Encapsulación, atributos `private`, getters, setters, arreglos y programación orientada a objetos.

**Conclusiones clave:** La encapsulación permite proteger los datos de una clase mediante atributos privados y métodos de acceso. Los arreglos permiten almacenar varios elementos del mismo tipo y sus posiciones comienzan desde el índice 0. Estos conceptos permiten construir programas más organizados.

### Lección 7: Errores comunes, buenas prácticas y próximos pasos

**Duración:** 6 minutos y 4 segundos.

**Descripción:** Identifica errores frecuentes al programar en Java, aprende a interpretar los mensajes del compilador y descubre buenas prácticas para continuar aprendiendo.

**Temas principales:** Errores de sintaxis, errores lógicos, depuración y buenas prácticas de programación.

**Conclusiones clave:** Es importante revisar los mensajes de error para identificar el archivo, la línea y la causa del problema. También se recomienda utilizar nombres claros para las variables y métodos, mantener el código ordenado y consultar la documentación oficial de Java.

## Cómo utilizar el curso

1. Selecciona la lección que deseas aprender.
2. Reproduce el video correspondiente para conocer los conceptos y ejemplos.
3. Abre el enlace de la actividad práctica (Starter).
4. Escribe o completa el código solicitado en OnlineGDB.
5. Presiona el botón Run para ejecutar el programa y comprobar su funcionamiento.
6. Si tienes dificultades, consulta la versión resuelta (Completed) para comparar tu código y comprender la solución.

No necesitas crear una cuenta ni instalar Java en tu computadora para realizar las actividades.
