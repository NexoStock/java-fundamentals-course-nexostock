# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de ~1 hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo programación orientada a objetos. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: 52 minutos y 36 segundos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**📂 Repositorio de código fuente**: https://github.com/NexoStock/java-fundamentals-course-nexostock

## Secuencia de la lección

### Lección 1: ¿Qué es Java y la programación? (7 min 28 s)

- **Descripción**: Aprende qué es programar, qué es Java y ejecuta tu primer programa en un editor en línea.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=5x-kiMFexPY)
- **Conclusiones clave**: Programar es dar instrucciones en orden; `System.out.println` muestra mensajes en la consola.
- **Empieza a programar**: [Abrir el editor](https://onlinegdb.com/czfku0bZ_) 👈 **¡No necesitas registrarte!**

### Lección 2: Variables, tipos de datos y operadores (10 min 31 s)

- **Descripción**: Aprende a guardar datos con variables y a hacer cuentas con operadores.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=I1C-HpcrygQ)
- **Conclusiones clave**: Usa `int`, `double`, `String` y `boolean`; declara como `int edad = 15;`.
- **Práctica**: [Clic para programar](https://onlinegdb.com/kBRXm3MJy) 👈 **¡No necesitas registrarte!**

### Lección 3: Estructuras de control: decisiones y bucles (9 min 11 s)

- **Descripción**: Toma decisiones con if-else y repite tareas con for y while.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=p5-kddtUJPc)
- **Conclusiones clave**: `if (edad >= 12) { }`; `for (int i = 1; i <= 5; i++) { }`; `while` repite mientras se cumpla una condición.
- **Práctica**: [Clic para programar](https://onlinegdb.com/t1kObfrQQ) 👈 **¡No necesitas registrarte!**

### Lección 4: Métodos y entrada de datos (6 min 09 s)

- **Descripción**: Crea código reutilizable con métodos y pide datos al usuario con `Scanner`.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=y0omaRM49B8)
- **Conclusiones clave**: `static void saludar(String nombre) { }`; `return` devuelve un resultado; `Scanner` lee la consola.
- **Práctica**: [Haz clic para practicar](https://onlinegdb.com/7OKjzEcrg) 👈 **¡No necesitas registrarte!**

### Lección 5: Clases y objetos: tu primera mascota virtual (6 min 03 s)

- **Descripción**: Entiende qué son una clase y un objeto, y crea una mascota virtual con constructor y métodos.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=3WO3QU8wjgU)
- **Conclusiones clave**: Clase = molde, objeto = cosa creada con el molde; `new` crea objetos y el constructor les da sus datos.
- **Práctica**: [Clic para programar](https://onlinegdb.com/jFV0FlGWt) 👈 **¡No necesitas registrarte!**

### Lección 6: Encapsulación, arreglos y tu primer programa (7 min 15 s)

- **Descripción**: Protege los datos con `private`, getters y setters, y construye un registro de estudiantes con un arreglo de objetos.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=926HeQEy4K4)
- **Conclusiones clave**: Encapsulación con getters y setters; los arreglos empiezan en 0; construye un programa orientado a objetos.
- **Proyecto final**: [Crea tu registro](https://onlinegdb.com/Zo7DAnLHa) 👈 **¡No necesitas registrarte!**

### Lección 7: Errores comunes, buenas prácticas y próximos pasos (5 min 59 s)

- **Descripción**: Conoce cinco errores típicos, cómo leer los mensajes del compilador y dónde aprender más.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=KYEoRpfMums)
- **Conclusiones clave**: Lee el mensaje de error (archivo, línea y causa); usa nombres claros y explora la documentación oficial de Java.
- **Práctica**: [Corrige el programa](https://onlinegdb.com/b7-OKiz1XT) 👈 **¡No necesitas registrarte!**
