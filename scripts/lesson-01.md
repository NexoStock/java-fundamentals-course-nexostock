### Escena 2 · 0:40–1:42 · ¿Qué es programar?

**Pantalla:**

Mostrar el título «Programar = dar instrucciones en orden».

Presentar una receta sencilla para preparar un sándwich. Animar tres pasos: colocar el pan, agregar queso y colocar el segundo pan. Utilizar flechas para mostrar que las instrucciones siguen una secuencia.

**Narración:**

Programar consiste en escribir instrucciones para que una computadora realice determinadas tareas. Pero ¿qué significa eso realmente? Imagina que quieres preparar un sándwich. Primero tomas una rebanada de pan, después agregas queso y finalmente colocas otra rebanada encima. Si realizas los pasos en el orden correcto, obtienes el resultado esperado.

Con las computadoras ocurre algo parecido. Necesitamos indicarles qué hacer y en qué orden. La diferencia es que una computadora sigue nuestras instrucciones exactamente como las escribimos. Por eso, programar requiere pensar de manera ordenada y dar indicaciones claras.

### Escena 3 · 1:42–2:35 · ¿Qué es Java?

**Pantalla:**

Mostrar el texto «Java = lenguaje de programación».

Presentar ejemplos de videojuegos, aplicaciones y sistemas empresariales. Resaltar la frase «Un lenguaje para dar instrucciones».

**Narración:**

Ahora que sabemos qué significa programar, conozcamos Java. Java es un lenguaje de programación, es decir, una forma de escribir instrucciones que una computadora puede procesar.

Este lenguaje se utiliza para desarrollar diferentes tipos de aplicaciones y sistemas. Una de sus ventajas es que nos ayuda a aprender conceptos fundamentales que también encontraremos en otros lenguajes de programación.

Durante este curso utilizaremos Java para comprender cómo funcionan las instrucciones, las variables, las decisiones y otros elementos que forman parte de un programa.

### Escena 4 · 2:35–3:34 · ¿Cómo funciona un programa?

**Pantalla:**

Mostrar una animación con tres pasos conectados mediante flechas:

**1. Escribir código → 2. Compilar → 3. Ejecutar**

Resaltar el término «Compilador = traductor del código». Mostrar un ejemplo sencillo de instrucciones escritas en el editor.

**Narración:**

Cuando programamos, escribimos instrucciones en un lenguaje como Java. A ese conjunto de instrucciones lo llamamos código fuente.

Pero la computadora necesita que ese código sea preparado para poder ejecutarlo. Para ello interviene una herramienta llamada compilador, que funciona como un traductor y también ayuda a detectar errores en lo que escribimos.

Podemos imaginar el proceso en tres pasos: primero escribimos nuestro código, después el compilador lo revisa y lo transforma, y finalmente el entorno de Java permite ejecutar el programa.

Lo mejor es que nuestro editor en línea se encargará de estos pasos cuando presionemos el botón Run.

Estas tres partes serán muy importantes durante nuestras prácticas. Ahora que conocemos el editor, estamos listos para escribir nuestro primer programa.

### Escena 6 · 4:37–6:13 · Nuestro primer programa

**Pantalla:**

Mostrar el siguiente código Java en OnlineGDB:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hola, mundo!");
    }
}
```

Resaltar únicamente la línea `System.out.println("Hola, mundo!");`.

Mostrar visualmente las comillas, el texto y el punto y coma. Después presionar **Run**, señalar la consola y mostrar el resultado:

```text
Hola, mundo!
```

Incluir la anotación «println = mostrar un mensaje».

**Narración:**

Este es nuestro primer programa en Java. Al principio puedes observar varias líneas que parecen complicadas, pero no te preocupes. Por ahora las utilizaremos como parte de la estructura básica de nuestro programa.

Vamos a concentrarnos en una instrucción muy importante: Sístem punto aut punto print ele ene.

Esta instrucción nos permite mostrar mensajes en la consola. Observa que el texto que queremos mostrar se encuentra entre comillas. En nuestro ejemplo escribimos Hola, mundo.

También podemos ver que la instrucción termina con un punto y coma. Este símbolo ayuda a indicar dónde termina la instrucción.

Ahora presionaremos el botón Run para ejecutar el programa. ¡Mira! En la consola aparece el mensaje Hola, mundo.

¡Felicidades! Acabas de ejecutar uno de los programas más conocidos para comenzar a aprender programación.
