# Curso de Fundamentos de Java para Principiantes

## Descripción del curso

Este curso de aproximadamente una hora está diseñado para introducir a estudiantes principiantes al mundo de la programación utilizando Java. A lo largo de siete lecciones, aprenderás los conceptos fundamentales del lenguaje, desde las variables y estructuras de control hasta la programación orientada a objetos.

No necesitas experiencia previa en programación ni instalar programas en tu computadora. Todas las actividades prácticas se realizan directamente desde el navegador utilizando [OnlineGDB](https://www.onlinegdb.com/), un entorno de programación en línea que permite escribir, ejecutar y probar código Java.

**Duración total:** 52 minutos y 42 segundos.

**Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa en programación.

**Prerrequisitos:** Ninguno.

**Herramientas necesarias:** Un navegador web actualizado y conexión a Internet.

**Repositorio del curso:** https://github.com/NexoStock/java-fundamentals-course-nexostock

## Contenido del curso

El curso está organizado en siete lecciones progresivas. Cada una presenta conceptos nuevos y propone una actividad práctica para reforzar lo aprendido.

### Lección 1: ¿Qué es Java y la programación?

- **Duración:** 7 minutos y 28 segundos.
- **Descripción:** Aprende qué significa programar, conoce el lenguaje Java y ejecuta tu primer programa utilizando un editor en línea.
- **Temas principales:** Introducción a la programación, Java y `System.out.println`.
- **Video:** https://www.youtube.com/watch?v=5x-kiMFexPY
- **Práctica (Starter):** https://onlinegdb.com/czfku0bZ_
- **Solución (Completed):** https://onlinegdb.com/pw1mdZHD1

### Lección 2: Variables, tipos de datos y operadores

- **Duración:** 10 minutos y 30 segundos.
- **Descripción:** Aprende a almacenar información mediante variables y realiza operaciones matemáticas utilizando diferentes tipos de datos.
- **Temas principales:** `int`, `double`, `String`, `boolean` y operadores.
- **Video:** https://www.youtube.com/watch?v=I1C-HpcrygQ
- **Práctica (Starter):** https://onlinegdb.com/kBRXm3MJy
- **Solución (Completed):** https://onlinegdb.com/naEfYc66U

### Lección 3: Estructuras de control: decisiones y bucles

- **Duración:** 9 minutos y 11 segundos.
- **Descripción:** Aprende a controlar el comportamiento de tus programas mediante condiciones y estructuras repetitivas.
- **Temas principales:** `if`, `else`, `for` y `while`.
- **Video:** https://www.youtube.com/watch?v=p5-kddtUJPc
- **Práctica (Starter):** https://onlinegdb.com/t1kObfrQQ
- **Solución (Completed):** https://onlinegdb.com/WlJu2b9uJ

### Lección 4: Métodos y entrada de datos

- **Duración:** 6 minutos y 9 segundos.
- **Descripción:** Descubre cómo organizar y reutilizar código mediante métodos. También aprenderás a recibir información del usuario utilizando Scanner.
- **Temas principales:** Métodos, parámetros, valores de retorno y entrada de datos con `Scanner`.
- **Video:** https://www.youtube.com/watch?v=y0omaRM49B8
- **Práctica (Starter):** https://onlinegdb.com/7OKjzEcrg
- **Solución (Completed):** https://onlinegdb.com/oPTjaj_KF

### Lección 5: Clases y objetos: tu primera mascota virtual

- **Duración:** 6 minutos y 2 segundos.
- **Descripción:** Conoce los fundamentos de la programación orientada a objetos y crea una mascota virtual utilizando clases, objetos y constructores.
- **Temas principales:** Clases, objetos, atributos, métodos y constructores.
- **Video:** https://www.youtube.com/watch?v=3WO3QU8wjgU
- **Práctica (Starter):** https://onlinegdb.com/jFV0FlGWt
- **Solución (Completed):** https://onlinegdb.com/4hrZk1ox5

### Lección 6: Encapsulación, arreglos y tu primer programa

- **Duración:** 7 minutos y 18 segundos.
- **Descripción:** Aprende a proteger los datos mediante la encapsulación y utiliza arreglos de objetos para desarrollar un pequeño registro de estudiantes.
- **Temas principales:** `private`, getters, setters, arreglos y programación orientada a objetos.
- **Video:** https://www.youtube.com/watch?v=926HeQEy4K4
- **Práctica (Starter):** https://onlinegdb.com/Zo7DAnLHa
- **Solución (Completed):** https://onlinegdb.com/lQ0qkJ07K

### Lección 7: Errores comunes, buenas prácticas y próximos pasos

- **Duración:** 6 minutos y 4 segundos.
- **Descripción:** Identifica errores frecuentes al programar en Java, aprende a interpretar los mensajes del compilador y descubre buenas prácticas para continuar aprendiendo.
- **Temas principales:** Errores de sintaxis, errores lógicos, depuración y buenas prácticas.
- **Video:** https://www.youtube.com/watch?v=KYEoRpfMums
- **Práctica (Starter):** https://onlinegdb.com/b7-OKiz1XT

## Cómo utilizar el curso

1. Selecciona la lección que deseas aprender y reproduce su video.
2. Cuando se indique durante el video, abre el enlace de la práctica (Starter).
3. Escribe o completa el código solicitado en OnlineGDB.
4. Presiona el botón Run para ejecutar tu programa y comprobar los resultados.
5. Si tienes dificultades, puedes consultar la solución (Completed) para comparar tu código.

No necesitas crear una cuenta ni instalar Java en tu computadora para realizar las actividades.
